# Contributing

Terima kasih sudah mau bantu atau memperbaiki repo ini — tujuan repo ini adalah catatan belajar pribadi yang juga bisa dipakai orang lain. Tulisan di sini singkat saja supaya gampang diikuti.

1. Sebelum mengirim issue/PR
- Cek dulu isi repo dan README — mungkin masalah atau ide sudah ada.
- Jika ingin menambah contoh baru, pastikan namanya jelas (mis. `binarySearch.cpp`, `MiniATM/ATM.cpp`).

2. Melaporkan bug / minta fitur
- Buka Issues dan jelaskan singkat:
  - Judul jelas (mis. "bug: crash di SelectionSort dengan input kosong").
  - Langkah reproduksi, input yang dipakai, output yang diharapkan.
  - File terkait kalau ada.

3. Cara kontribusi kode
- Fork repo → buat branch baru dengan format `feat/<nama>` atau `fix/<nama>`.
- Jangan commit langsung ke `main`.
- Sertakan komentar singkat di awal file untuk jelaskan fungsi/tujuan.
- Untuk C++ gunakan standar C++17.

4. Commit message
- Ringkas dan jelas. Contoh:
  - `add: binary search example`
  - `fix: typo in SelectionSort output`
  - `docs: update README`

5. PR checklist (singkat)
- [ ] Kode bisa dikompilasi (jika C++/Java) dan dijalankan.
- [ ] Ada komentar/penerangan singkat untuk yang baru ditambahkan.
- [ ] Deskripsi PR menjelaskan perubahan dan kenapa perlu.

6. Style sederhana
- C++: C++17, indentasi konsisten (2 atau 4 spasi — pilih salah satu dan pakai konsisten).
- JavaScript/Python/Java: cukup kode yang bersih dan komentar bila perlu.

7. Lisensi dan credit
- Kalau mengambil potongan kode dari sumber lain, cantumkan sumber/credit.
- Perhatikan LICENSE di repo (kalau ada).

8. Pertanyaan
- Mention owner: @RyuuZev

Terima kasih! Kalau mau, saya bisa bantu bikin ISSUE_TEMPLATE atau PR template juga.
